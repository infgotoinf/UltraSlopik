# Источники

Требования: шесть методических документов Этап1–Этап6 и Учебная_практика_№3_УП03.xlsm
из родительской папки. Дата ознакомления: 29.10.2026.

- Python sqlite3, транзакции и backup: https://docs.python.org/3/library/sqlite3.html
- Ограничения встроенного HTTP-сервера: https://docs.python.org/3/library/http.server.html
- Ruff, установка: https://docs.astral.sh/ruff/installation/
- OSV API для dev-зависимости: https://api.osv.dev/v1/query

Результаты тестов, времени ответа и восстановления получены локально,
а не взяты из внешних примеров.
