# Производительность

29.10.2026, локальная машина Windows, Python 3.12.14. Синтетическая SQLite,
2 заявки текущего пользователя. 100 последовательных GET /api/tickets,
один клиент; авторизация заранее, пароль не входит в время запросов.

Среднее 2.33 мс, p95 11.15 мс, максимум 18.17 мс.
Ошибок 0. Критерий учебного smoke: p95 <1000 мс и 0 ошибок — выполнен.
Метод: perf_counter вокруг полного чтения HTTP-ответа; p95 — 95-й элемент 100 значений.

Chrome CDP: DOMContentLoaded 9.10 мс, load 11.50 мс; три запроса при смене
статуса/чтении списка вернули 200; необработанных JS exceptions 0.
Это единичный локальный замер; холодный старт, Интернет, параллельная нагрузка
и большая БД не исследовались. Полный JSON и CDP-результат приложены в reports.

Повторить: python tools.py performance. Не объявляем этот замер доказательством
производственной масштабируемости. Следующее улучшение — пагинация и параллельный профиль.
