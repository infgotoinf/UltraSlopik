# Инцидент сопровождения 001

Обращение: нужна выгрузка заявок для отчёта. Это небольшое улучшение эксплуатации,
допустимое для этапа 6. Локальная задача: docs/issues/001-export.md.

1. В v0.1.0 GET /api/export вернул 404. Запрос и код записаны в before_export.txt.
2. Лог содержит method=GET path=/api/export status=404. В dispatch отсутствовал
   маршрут экспорта, соединение с SQLite при этом работало. Причина — функция не реализована.
3. Создана отдельная ветка feature/export-tickets.
4. Добавлен helpdesk/export.py, маршрут GET, кнопка CSV, тесты доступа/состава/формул.
   Использован core.list_tickets: права и фильтр совпадают с просмотром.
5. Дополнительно устранён BUG-02: опрос статуса сессии на входе не создаёт ложный 401.
6. Выполнены 20 тестов, Ruff, live HTTP и скачивание в Chrome. CSV UTF-8 BOM,
   разделитель «;», опасные формулы нейтрализуются, поля с переносами сохраняются.
7. Изменения сохранены отдельным commit и влиты через merge --no-ff с описанием.
8. Подготовлены 0.1.1, CHANGELOG, release ZIP и workflow push/PR.

GitHub Issue/PR/Actions не создавались: работа ограничена локальной папкой.
Вместо сетевого PR оформлен локальный merge (допускается критерием этапа),
описание в docs/LOCAL_MERGE.md. Шаги CI реально выполнены локально, это не GitHub run.
