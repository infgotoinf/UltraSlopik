# Задача 001 Выгрузка заявок для отчёта

Тип: улучшение эксплуатации. Дата: 29.10.2026. Версия на входе: v0.1.0.
Окружение: Windows, Python 3.12.14, локальный demo http://127.0.0.1:8080.

Пользователю нужно приложить свои обращения к отчёту, сотруднику — выгрузить все
обращения корпуса. В прототипе нет экспорта. GET /api/export возвращает 404,
в журнале сервера виден соответствующий запрос. Это отсутствие функции, а не сбой БД.

Шаги: запустить demo; войти как student; запросить GET /api/export.
Ожидание: CSV с собственными заявками. Факт: 404 «Маршрут не найден».

Критерии приёмки: ответ 200 и CSV; пользователь получает только свои записи;
admin получает все записи; фильтр статуса сохраняется в выгрузке; формулы из
пользовательского ввода не исполняются при открытии CSV; без сессии ответ 401.

Ветка: feature/export-tickets. Связанный журнал: INCIDENT_REPORT.md.
Задача хранится локально. GitHub Issue не создавался.
