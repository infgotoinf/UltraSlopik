# Развертывание учебного стенда

Выбран локальный demo с переносимой сборкой PYZ/ZIP. Он запускается без IDE,
не требует установки серверной БД и не создаёт внешних ресурсов.
Адрес: http://127.0.0.1:8080. Требования: Python 3.12+, доступный порт, запись в папку.

Из исходников: `python tools.py deploy`; проверить `python tools.py check-deploy`;
логи `python tools.py logs`; перезапуск `python tools.py restart`;
остановка `python tools.py stop`. Процесс стартует в фоне без нового окна Windows.
Перед остановкой проверяется PID отвечающего экземпляра.

Из релиза: распаковать release/ServiceDesk-0.1.1.zip в новую папку;
выполнить `python servicedesk.pyz` или start.bat. Открыть адрес и проверить сценарий.
Остановка Ctrl+C, повторный запуск той же командой. Данные сохраняются рядом с билдом.
Сборка: `python tools.py build`, результат dist/ServiceDesk-0.1.1.zip.

После restart сервер снова отвечает 200, версия 0.1.1, PID изменился.
Release smoke дополнительно запускает PYZ из новой распакованной папки,
входит, создаёт заявку, останавливает процесс, запускает снова и читает ту же заявку.
Результаты — logs/release_smoke.txt и logs/restart.txt в этапах сдачи.

docker-compose.prod.yml — подготовленный локальный demo-профиль с restart,
read_only и сброшенными capabilities. Не публиковался и не запускался.
Nginx, VPS и systemd не применяются: выбран локальный переносимый вариант.
Production-шаблон предусмотрен для последующей адаптации; публичный режим
текущий учебный сервер блокирует.
