# Быстрая демонстрация

Python 3.12+. Запустить `python run.py` из исходников или `python servicedesk.pyz`
из распакованного релиза. Открыть http://127.0.0.1:8080.

Учебные аккаунты: student — свои заявки; other — другой пользователь;
admin — все заявки и смена статуса. Публичный demo-пароль у всех: StudentDemo42!.

1. student: создать «Не работает принтер», приоритет высокий.
2. Убедиться, что заявка появилась. Скачать CSV, проверить строку.
3. Выйти. Войти admin: открыть новую заявку и перевести в «В работе».
4. Выйти. Войти student: увидеть новый статус.
5. Войти other: заявка student отсутствует.
6. Показать `python tools.py check` и `python tools.py backup`.

Успех: данные реально сохранены, права различаются, ошибки ввода обрабатываются,
после перезапуска обращения остаются в SQLite. Не размещать demo в интернете.
