# Безопасность учебного ServiceDesk

Рабочая область — локальная машина, loopback. Только учебные данные.
Роли проверяются сервером, владельца задаёт сервер. SQL параметризован.
Пароли хешируются PBKDF2-SHA256 с солью, сессии истекают через час;
выход и восстановление БД отзывают сессии. Cookie HttpOnly/SameSite=Strict.
Проверяются Host, Origin и CSRF, выставлены CSP, nosniff, DENY.
В лог не записываются Cookie, тело запроса, пароли и query string.

Обнаруженную проблему локально описать в docs/issues/ с шагами и эффектом,
не добавляя реальные пароли, cookie и персональные данные. Перед исправлением
сохранить backup и добавить регрессионный тест нарушенного правила.

Ограничения: HTTP без TLS, встроенный учебный сервер, нет распределённого
ограничения входа, нет автоматической удалённой копии и промышленного мониторинга.
Запрос OSV относится только к Ruff, а не к безопасности всей ОС/CPython.
