# Паспорт проекта

Название: ServiceDesk — учёт заявок в техподдержку учебного корпуса.
Автор: Манько Аким. Группа: ____________________. Практика: УП.03, ПМ.03,
специальность 09.02.07. Дата: 29.10.2026.

Цель: не терять обращения о неисправностях и видеть их состояние.
Пользователи: студент и сотрудник поддержки. Функции: вход, создание и чтение
собственных заявок, фильтр статуса, смена статуса сотрудником, выгрузка CSV.

Стек: Python 3.12+, sqlite3, HTTP/JSON, HTML/CSS/JavaScript без фреймворков.
Проверено: Python 3.12.14 и 3.15.0rc2, Ruff 0.14.3, Chrome.
Внешних runtime-зависимостей нет. Архитектура: один процесс и встроенная БД.

минимальный самостоятельный прототип v0.1.0, затем выполнен цикл сопровождения
до v0.1.1. Документы УП.02 задним числом не выдаются за ранее выполненную работу.
