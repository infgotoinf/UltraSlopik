# Конфигурация

Файл .env читается из текущей папки проекта. ENV_FILE выбирает другой файл.
Переменные процесса имеют приоритет. Настоящих токенов или SECRET_KEY не требуется.

| Параметр | Пример | Назначение |
|---|---|---|
| APP_ENV | development / demo | Режим; production запрещён для встроенного сервера |
| APP_HOST | 127.0.0.1 | Только локальный интерфейс; 0.0.0.0 внутри контейнера |
| APP_PORT | 8080 | TCP-порт HTTP |
| DB_PATH | data/helpdesk.db | Путь к SQLite, создаётся автоматически |
| DEMO_SEED | true | Создать только пустую учебную БД с тестовыми аккаунтами |
| ALLOWED_HOSTS | 127.0.0.1,localhost | Допустимые Host, без порта |
| ENV_FILE | .env.demo | Путь к файлу настроек |
| APP_DEBUG | false | Документирует режим, traceback в HTTP-ответы не выводится всегда |

Сессия: случайный токен, в БД хранится SHA-256 токена, срок 1 час.
Cookie HttpOnly, SameSite=Strict. Пароли: PBKDF2-SHA256, 600000 итераций и случайная соль.
Порт БД не открыт: отдельного сетевого сервиса SQLite нет.
Пример demo: скопировать .env.demo.example в .env либо оставить defaults.
