# Релиз ServiceDesk 0.1.1

Дата: 29.10.2026. Автор: Манько Аким.

Теперь заявки можно скачать в CSV для учебного отчёта. Пользователь выгружает
свои обращения, сотрудник поддержки — все. Выбранный фильтр применяется к файлу.
Также убрано лишнее сообщение 401 при первом открытии страницы входа.

Запуск: распаковать архив, установить Python 3.12+, выполнить `python servicedesk.pyz`.
Открыть http://127.0.0.1:8080. student/other/admin, demo-пароль StudentDemo42!.
Остановка Ctrl+C. Данные в data/helpdesk.db сохраняются между запусками.

Проверка: создать заявку, скачать CSV, войти admin, сменить статус, перезапустить
и увидеть сохранённые данные. Релиз проверен из отдельно распакованной папки без IDE.
Исходники: 20 бизнес-тестов и HTTP-проверок в unittest, lint/format Ruff.

Ограничения: нужен Python; только локальный demo; фильтр не сохраняется после reload;
нет пагинации, расписания backup, TLS и промышленного HTTP-сервера.
Архив не содержит пользовательскую БД, .env, логи, pip-пакеты и секреты.
