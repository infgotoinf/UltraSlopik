# Входной аудит

На входе: шесть методических документов, учебный план XLSM, пустая папка результата.
Кода, репозитория и материалов УП.02 не было. Базовый проект восстановлен как
учебный прототип v0.1.0. Это исходная точка локальной истории Git.

| Компонент | На входе | Итог |
|---|---|---|
| Код и БД | Отсутствуют | helpdesk/, schema.sql, SQLite |
| Описание и запуск | Отсутствуют | README, INSTALL, BAT, Makefile |
| Настройки | Отсутствуют | .env.example, demo и production-шаблоны |
| Проверки | Отсутствуют | 20 проверок бизнес-логики и HTTP |
| Эксплуатация | Отсутствует | deploy/restart/health, logs, backup/restore |
| История | Отсутствует | локальный Git, теги, ветка, merge и bundle |

Состав: helpdesk/core.py — данные и права; server.py — API/CLI; static/ — UI;
schema.sql — миграция 1; tests/ — сценарии; tools.py — переносимые команды;
scripts/ — Windows-обёртки; docs/issues/ — задача поддержки; .github/ — workflow.

Настроек почты и JWT нет: эти функции не используются. Отдельный сервер БД
не нужен: SQLite работает в процессе. Следующие задачи: установка, переносимая
сборка, измерение качества, проверка доступа, оформление улучшения.
